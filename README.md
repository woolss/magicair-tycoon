# MagicAir Tycoon

Казуальна гра про магазин гелієвих кульок. Phaser 3, працює в браузері.

**Етап 0 — сірий прототип:** одна зміна, клієнти, збирання набору, надування, таймер, підсумок дня. Кружки замість арту — перевіряємо, чи весело.

## Структура

- `src/config.js` — усі числа гри (ціни, час, терпіння, гелій)
- `src/logic.js` — логіка зміни без Phaser (тестується в node)
- `src/scenes/` — екрани: старт, зміна, підсумок
- `src/i18n.js` — написи: українська (основна), російська
- `test/` — тести логіки: `npm test`
- `sim/economy_sim.py` — симулятор економіки: `python3 sim/economy_sim.py`

## Параметри URL для тестів

`?lang=ru` — російська, `?shift=30` — зміна 30 с, `?seed=1` — фіксовані клієнти.

## Правила

- Жодних секретів у репо (ключі, токени, промокоди).
- Жодного тексту всередині картинок — всі написи малює гра.
- Гроші — цілі числа.
