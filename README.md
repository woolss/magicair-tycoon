# MagicAir Tycoon

Казуальна гра про магазин гелієвих кульок. Phaser 3, працює в браузері.

**Етап 1 — ріст (сірий прототип):** зміна 3 хв, склад і закупівля між днями, 6 апгрейдів (насоси, вивіска, конфеті, фольга, балон 200), збереження в браузері. Кружки замість арту.

## Структура

- `src/config.js` — усі числа гри (ціни, час, терпіння, гелій)
- `src/logic.js` — логіка зміни без Phaser (тестується в node)
- `src/run.js` — стан між змінами: каса, склад, апгрейди, збереження
- `src/studio.js` — окремі покупки косметики, вибір залу й одягу, праві полиці для декору
- `src/scenes/` — екрани: старт, зміна, підсумок, закупівля/апгрейди
- `src/i18n.js` — написи (українська)
- `test/` — тести логіки: `npm test`
- `sim/economy_sim.py` — симулятор економіки: `python3 sim/economy_sim.py`
- `sim/bot_days.js` — бот грає справжню логіку 20 днів: `node sim/bot_days.js`

## Параметри URL для тестів

`?shift=30` — зміна 30 с, `?seed=1` — фіксовані клієнти.

«Студія» з'являється на екрані підготовки після купівлі переїзду в магазин. Кожна розцвітка, форма для конкретного продавця та предмет декору купується окремо. Куплене можна перемикати без повторної оплати; стан зберігається разом із грою. Декор займає лише три короткі полиці праворуч. Ці покупки не змінюють правила зміни та доходи.

## Правила

- Жодних секретів у репо (ключі, токени, промокоди).
- Жодного тексту всередині картинок — всі написи малює гра.
- Гроші — цілі числа.
